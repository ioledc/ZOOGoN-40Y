# Preprocess MC Surveys

This function preprocesses raw MC survey data. It performs data cleaning
and transformation

## Usage

``` r
preprocess_surveys(raw_data = NULL)
```

## Arguments

- raw_data:

  Data to preprocess.

## Value

Preprocessed data

## Examples

``` r
if (FALSE) { # \dontrun{
preprocess_surveys()
} # }
```
